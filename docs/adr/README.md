# Architecture Decision Records

ADRs capture decisions that materially shape the hackathon product. They are
short, implementation-oriented, and optimized for keeping the team aligned
under time pressure.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](0001-shiftahead-hackathon-product-and-architecture.md) | Accepted | ShiftAhead hackathon product, architecture, scope, and demo loop |

New durable decisions should be recorded in a new ADR rather than rewriting the
history of an accepted decision.
